# Платформа "Образоваттельные модули"
---
В данном модуле создаются курсы и уроки к ним привязываютс ученики

Ученики могут просматривать уроки

Пользователь с правами " is staff" могут просматривать, редактировать курсы и уроки, и назначать их ученикам.

Пользователь с правами администратора могут контролировать все функции данной платформы

## Приложение имеет API-интерфейс и протестировано на Postman

## Для запуска Doker введите команду:
 docker-compose -d --build
